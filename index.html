About Us

Built by one topper, for every future topper

CETWALLE is built and published entirely by Harshvardhan Raut — every question, every note, every line of code on this platform is made by one person, not a company or a coaching franchise. It's currently maintained by him while pursuing IT at PICT (Pune Institute of Computer Technology), Pune.

05 · Exam-Time Security

The security wall doesn't come down once the exam starts

  • Students can't break the security wall while a mock is running — browser dev tools can't be used to pull questions or answers mid-exam
  • Questions travel through a very high level of encryption end-to-end, so there's no bypassing the exam portal to access them directly
  • Every mock generates its own session token, valid only for the device that started the exam — it can't be reused or shared from another device
  • If someone tries to access the exam from a second device using the same session, it simply won't work — the token is locked to the original device
  • Timing for every single question is tracked individually for each student, not just the total test time
  • That question-wise timing is shown back to the student on the review page after the exam, as part of their performance analysis
  • All of this runs quietly in the background — students get a smooth exam experience with none of the security machinery visible or in the way
